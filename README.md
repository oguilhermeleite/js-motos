# JS Moto Peças

Página de apresentação e link direto para a JS Moto Peças - Sua boutique das motos.

**Qualidade • Performance • Confiança**

## Funcionalidades

- Logo profissional do S1000 RR
- 3 botões de ação principais:
  - Atendimento via WhatsApp
  - Localização (Google Maps)
  - Instagram
- Seção de serviços
- Informações de contato

## Deploy

Hospedado na Vercel. Acesso via link.bio do Instagram.
